# CUBOCCI STUDIO ブランドスタイルガイド

`creator` エージェントが台本・インフォグラフィック・note挿絵・WEB（LP）を作る際に必ず参照する統一ルール。
2026-09-11、オーナーから共有された参考ワインインフォグラフィック9点の分析をもとに、
既に `winedeck/winedeck.py` と `docs/content.json`（LP）で実際に使われていた配色・書体を正式なブランドとして確定した
（参考画像そのものは著作権不明の外部素材のためリポジトリには含めていない）。

## カラーパレット（確定・全出力物で統一）

2026-10改訂：参考アカウント「視覚のきほん」シリーズの実例（複数投稿）を分析し、
**ワインレッドを廃止**。ダークグリーン×ゴールド×クリームの2トーン構成に統一した。

| 用途 | 色 | HEX | 使用箇所 |
|---|---|---|---|
| 表紙・締め背景（ダークグリーン） | 深い森green | `#2A3B23` → `#0F170B`（グラデ） | `wine_type="classic"`（cover/summaryスライド） |
| アクセント（ゴールド） | 金 | `#C9A84C` | 枠線・区切り線・バッジ・数字circle |
| アクセント（ダークゴールド／本文見出し用） | 金茶 | `#A6791F` | クリーム背景でのeyebrow・強調文字 |
| アクセント（明ゴールド／暗背景用） | 淡い金 | `#E3C76B` | ダークグリーン背景でのsubtitle・強調文字 |
| 背景（クリーム・本文） | アイボリー | `#F7F2E4` → `#EFE4CB`（グラデ） | `wine_type="brand"`（本文スライド） |
| 本文（明地） | 濃グレー | `#2B2B2B` | |
| 本文（暗地） | オフホワイト | `#F5F5F0` | |
| 補助テキスト（明地） | 温かみのあるグレー | `#8A7A5E` | |

- **ワインレッド（`#6B1A2A`）は使わない**。旧版では`PAL["brand"]`のアクセント色だったが、
  参考アカウントの実例にワインレッドが一切登場しないため廃止した。
- 表紙・まとめスライドは`wine_type="classic"`（ダークグリーン）、本文スライドは`wine_type="brand"`
  （クリーム）を1つのデッキ内でスライドごとに使い分けるのが標準パターン（`winedeck.py`の`PAL`参照、
  各スライドJSONで`wine_type`を個別指定できる）。
- ワインタイプ別インフォグラフィック（赤・白・ロゼ・オレンジ等）は `winedeck.py` の `PAL` に既存の
  タイプ別配色があるので、その一貫性を優先する（上記配色に強制的に統一しない）。

## タイポグラフィ

- 見出し：明朝体 `Noto Serif CJK JP` → `Yu Mincho` → `Hiragino Mincho ProN`（LPでは `Cormorant Garamond` 等の欧文セリフ＋和文明朝の組み合わせ）
- 本文：ゴシック体 `Noto Sans CJK JP` → `Yu Gothic` → `Hiragino Sans`
- 見出し＝上品・伝統、本文＝読みやすさ、の役割分担を崩さない。

## 参考資料から抽出した「見せ方」の型

添付いただいた9枚のワイン系インフォグラフィックに共通する要素：

1. **タイトルは大きく・遊びのある強調**（色文字・吹き出し・バッジ）で「これは何の話か」を1秒で伝える。
2. **番号解説（01/02/03…）**でセクションを区切り、情報の多さを「迷わない構造」に変換している。
3. **アイコン・イラストで文字を減らす**（果物アイコン＝香りの例、温度計＝提供温度、など）。
4. **比較・ランキング・フロー・4象限**など、「一覧性の高い型」を多用し、スワイプ/スクロールで止まらせる。
5. **出典明記・豆知識コーナー**など、信頼感と読了後のもう一押しを入れる。
6. 配色は資料ごとにバラバラ（オレンジ、ボルドー、ネイビー等）だが、CUBOCCI STUDIOでは上記カラーパレットに統一することで「型は参考にしつつ、色は自分のブランドとして一貫させる」方針を取る。

`icon_grid` / `flow` / `ranking` / `quadrant`（`winedeck/`に追加済み）は、上記2〜4の型をブランドカラーで
再現するためのテンプレート。新しい型が必要な場合は `winedeck.py` の既存プリミティブ（`_header` / `_hair` /
`_eyebrow` / `_footer` / `_t`）を使って追加してよい。

## 生成方式の使い分け

| 目的 | 使う仕組み |
|---|---|
| 数値・比較・手順など**正確なテキスト配置が必要**なインフォグラフィック | `winedeck/`（SVGエンジン。日本語が崩れない。`render.py` にJSON仕様を渡す） |
| 世界観・雰囲気を伝える**写真的・情緒的なビジュアル**（表紙、世界観カット） | `tools_video.generate_scene_image`（gpt-image-1）。プロンプトに上記カラーパレット・トーンを含める |
| より高品質な動画クリップ・モーション素材が要る場合 | Higgsfield（`tools_video.generate_scene_video`、`@video`エージェント経由）。**課金APIのため、使用前に必ずオーナーの許可を得る**（[[feedback_confirm_before_paid_api]]） |
| note記事の挿絵 | 上記2方式のいずれか、記事の内容に応じて選ぶ |
| LP・WEBページ | `tools_lp.py`（`docs/content.json` → `docs/index.html`）。フォント/配色は本ガイドと同一の `elegant` 系を既定にする |

## 運用ルール

- 新しいインフォグラフィックやLPページを作る際は、必ず上記カラーパレットとタイポグラフィから始める。
  資料ごとに独自配色を作らない（統一感の欠如を避けるのが本ガイドの目的）。
- 資料系コンテンツで「完全初心者向け」と「ソムリエ受験者向け（学術版）」の2パターン作成方針がある場合、
  インフォグラフィックでも同様に検討する（[[slides-two-versions]]）。
- winedeckは週次自動実行には組み込まれていない。Claude Codeでの `creator` 対話利用が対象。
